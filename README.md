# 🥷 Ninja Dev 3D - Next-Gen Edition

Um jogo interativo desenvolvido em Python com motor de projeção 3D nativo, física de partículas, renderização neon e alternância de mapas em tempo real.

## 🚀 Funcionalidades
- **Engine 3D Nativa:** Álgebra linear, rotação nos eixos X, Y e Z e projeção de perspectiva sem bibliotecas 3D externas.
- **Dual-Map System:** Alterne entre os cenários **Cyber Matrix** e **VS Code IDE Dark** (pressionando a tecla \`M\`).
- **Sistema de Dificuldade:** Níveis Júnior, Pleno e Sênior com variação de velocidade e taxa de bugs.
- **HUD Glassmorphism:** Indicadores de vida em xícaras 3D com fumaça animada.

## 💻 Como Executar

1. **Instalar dependências:**
   \`\`\`bash
   pip install pygame-ce
   \`\`\`

2. **Iniciar o jogo:**
   \`\`\`bash
   python app.py
   \`\`\`
